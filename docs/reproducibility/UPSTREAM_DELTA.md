# Upstream Delta: Official SimCortex v2.0 vs Fixed-Initialization MRI-Only Variant

## Baseline

This comparison uses the official `Neuro-iX/SimCortex` repository at:

`6f3cb21af9763807190407e9725331b0f2e78bed`

That revision is the SimCortex v2.0 journal-version implementation. It is distinct from the older v1.0.0 / `legacy/v1-shapemi2025` conference implementation.

## Official SimCortex v2.0 pipeline

The official full pipeline has four stages:

```text
raw T1 / FreeSurfer-derived inputs
        |
        v
1. preprocessing to MNI152
        |
        v
2. 9-class segmentation
        |
        v
3. InitSurf
   - subject-specific white/pial initialization
   - SDF / ribbon outputs
        |
        v
4. deformation
   - preprocessed MRI
   - ribbon probability
   - subject-specific initial surfaces
        |
        v
final cortical surfaces
```

The existence of an MRI-only preprocessing helper in the official pipeline does not make the official deformation network MRI-only. In the pinned upstream deformation configuration, `model.c_in=2` and the deformation dataset uses both MRI and ribbon probability.

## Official deformation contract

At the pinned upstream baseline, the deformation stage uses:

- MNI152 preprocessed T1 MRI from preprocessing;
- ribbon probability generated by InitSurf;
- subject-specific initial white/pial surfaces generated by InitSurf;
- `model.c_in=2`;
- `DualMUNetV2`;
- a dedicated geometry/probability encoder;
- `GeomInject` fusion between MRI and geometry/probability features;
- `geom_ratio=0.5`, `geom_depth=6`, and `gate_init=-3.0` in the default inference config.

Conceptually:

```text
MRI --------------------> MRI encoder -------+
                                             |
ribbon probability ---> geom/prob encoder ---+--> fused decoder --> SVFs

subject-specific InitSurf surfaces -------------------------------> vertices
```

## Fixed-initialization MRI-only experiment

The reconstructed experiment changes the deformation-stage input contract to:

- one MNI152 T1 MRI channel;
- no ribbon-probability conditioning;
- one fixed four-surface template shared across subjects within an experiment arm;
- no subject-specific InitSurf requirement for the final deformation inference path;
- `model.c_in=1`;
- `MUNetV2`, a single MRI encoder-decoder;
- no geometry/probability encoder;
- no `GeomInject` fusion.

Conceptually:

```text
MNI152 T1 MRI ---> single MRI encoder-decoder ---> four SVFs

fixed template surfaces ---------------------------> vertices
```

## What was deliberately preserved

The experiment changes initialization and conditioning, not the core diffeomorphic deformation mechanics.

After the network predicts the four stationary velocity fields, the clean variant preserves the same high-level sequence:

```text
SVF
 -> Gaussian smoothing
 -> scaling-and-squaring integration
 -> displacement interpolation at mesh vertices
 -> vertex coordinate update
```

This separation is important: the scientific comparison is primarily about what initialization can replace the original subject-specific InitSurf pathway and how fixed-template geometry affects downstream deformation behavior.

## Five arms are initialization conditions

The five final arms are:

- Sphere
- Random
- Original150k
- Curv0
- Curv1

They share the MRI-only deformation architecture. Their primary manipulated variable is the fixed initial surface geometry.

Therefore, the experiment should not be described as a comparison of five network architectures.

## Segmentation wording

The correct statement is:

> The fixed-initialization MRI-only deformation experiment removes the segmentation-dependent subject-specific initialization pathway from the final deformation input contract.

The following statement is too broad and should not be used:

> Segmentation was removed from SimCortex.

Official SimCortex v2.0 still contains segmentation as Stage 2 and InitSurf as Stage 3. Their implementations remain in this fork as upstream functionality. They are simply not required to provide the final deformation input for this fixed-template experiment.

## Preprocessing wording

Preprocessing was not removed.

The fixed-init model still consumes MNI152-aligned T1 MRI. The real-MRI reproduction used the historical `sc-preproc-0.2` HCP_YA input for `sub-135932` and successfully generated four valid cortical surfaces.

## Template preparation is not prediction postprocessing

The following operations belong to offline fixed-template preparation:

- ordinary Taubin smoothing;
- collision-aware Taubin smoothing;
- largest-connected-component cleanup;
- Geometry Central `adjustEdgeLengths()`;
- uniform edge-only remeshing;
- curvature-adaptive remeshing.

They prepare the shared initialization mesh before training/inference. They are not per-subject postprocessing steps applied to the network's predicted surfaces.

## Claims this branch supports

The evidence supports the following statements:

- the five final historical checkpoints are structurally compatible with the clean model;

- the five final arms test alternative fixed initialization geometries under the same MRI-only deformation architecture.

## Claims this branch does not make

The evidence does not support claiming that:

- official SimCortex v2.0 itself is MRI-only;
- segmentation or InitSurf were deleted from the official framework;
- the five arms are five separate neural-network architectures;
- offline template smoothing/remeshing is per-subject prediction postprocessing;
- the clean Narval smoke test is an exact replay of the historical Neuro-Ix sample40 external evaluation.

Historical Neuro-Ix launcher provenance was captured, but the exact historical sample40 MRI/preprocessing payload was not preserved locally before access ended. That limitation is intentional and explicit.
